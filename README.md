# птЫчка

**Язык программирования:** Swift

**Назначение:** Учебные работы, эксперименты со Swift, SwiftUI-приложения и будущие проекты для экосистемы Apple.

> Птичке полезны оба гнезда: Swift Package Manager и Xcode.

## Структура каталогов

```text
Labs/
Projects/<package>/Package.swift
Projects/<package>/Sources/
Projects/<package>/Tests/
Projects/<app>/<app>.xcodeproj
Experiments/
Documentation/
```

Реальные файлы лабораторных и проектов добавляются в соответствующие каталоги. Для нескольких C-программ, Python-скриптов или веб-сайтов заводи отдельную папку проекта.

## Запуск и сборка

Для Swift Package Manager установи Xcode Command Line Tools и выполняй команды внутри пакета:
```sh
cd Projects/<package>
swift build
swift run  # для исполняемого пакета
swift test
```
Xcode-проект открывай командой `open Projects/<app>/<app>.xcodeproj` или непосредственно в Xcode.

## Учебные работы и проекты

Пока реальные работы в репозитории не добавлены. По мере готовности указывай здесь название, краткую цель и ссылку на папку каждой работы или проекта. Демонстрационные заглушки не используются.

## Будущие дополнения

Добавляй новые лабораторные работы и самостоятельные проекты в соответствующие каталоги. Для каждого самостоятельного проекта сохраняй локальные инструкции по запуску, сборке и зависимостям.
